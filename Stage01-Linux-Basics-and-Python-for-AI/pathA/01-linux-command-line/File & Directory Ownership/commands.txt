WHAT YOU NEED WITH chmod Commande :

u = USER 
g = GROUP
a = ALL USERS
o = OTHERS

r = read 
w = write
x = execute

chmod = change permissions in the file or dir

ex : chmod u=rwx + file name = change per of that file to only this per

chmod u-rwx + file = remove per of that file 
chmod u+rwx + file = add this per to that file 

the binary type of permission get = r=4 w=2 x=1 

ex : chmod 444 + file name 

      first number place always for u
      the seconde number place for g
      the third number place for o 

so if you want to add 3 permession in u or g or o or all you just need to calculate in + the numbers 
ex : like if you want to do the per r=4 and e=1 in u you just 4+1=5 and write chmod 5 + file name 


if you want to do this recursivly =
chmod -R 777 + file name





chown = change ownership 
chown name of user + file name = change ownership of the file 
chgrp = change group ownership 
chgrp + name of groupe you want to change + file name = change owneship of the group
