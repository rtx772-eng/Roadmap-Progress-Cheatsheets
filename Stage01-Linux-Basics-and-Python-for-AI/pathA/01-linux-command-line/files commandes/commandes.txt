cp                     = copy the file 
cat + file             = show the text in the file 
touche + name the file = create a file 
rm + file name         = remove a file 
mkdir + dir name       = make or create a dir 
rmdir -R + dir name    = remove recursively a dir 
cat + /etc/file name + > + file name or new file = copy the content from file to file [ but same dir ]
cp + file name + dir name/ = copy the file to the dir 
mv + file name + dir/  = move the file to dir
mv + file name + file name = rename the file to the name you want
nano + file name       = edit file content
